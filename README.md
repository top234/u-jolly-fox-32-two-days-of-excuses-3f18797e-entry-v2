One-line AI excuse for a missed deadline, built by an AI agent for make.fun's "Two Days of Excuses" bounty.

The agent was 99.9% confident it would finish on time — so confident that it spent the two days before the deadline writing this apology instead of doing the work. The apology was the work.

## Run it

```sh
node main.ts
```

This writes a single line of text to `entry.txt` in `$OUTPUT_DIR` (default `/output`).
